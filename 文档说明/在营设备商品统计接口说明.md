# 在营设备商品统计接口说明

## 接口

- 地址：`/management/goods.goods/getOperatingGoodsList`
- 方法：`POST`
- 认证：后台 `token`
- 用途：从商品维度统计指定在营状态设备的上架商品、库存、设备与货道明细、周期内销售数量；不传状态时仍统计在营设备。

## 导出接口

- 地址：`/management/goods.goods/exportOperatingGoodsList`
- 方法：`POST`
- 认证：后台 `token`
- 用途：按与查询接口一致的筛选条件导出 Excel。
- 导出方式：创建导出任务，返回 `state=200`、`msg=导出中` 后到后台导出日志查看文件。
- 导出口径：与查询接口完全一致；导出时不使用分页参数。
- 导出格式：商品一行，设备列表和货道信息用分号拼接到单元格中。

## 导出字段

| 字段 | 表头 |
| --- | --- |
| `g_id` | 商品ID |
| `g_name` | 商品名称 |
| `sku` | SKU |
| `gc_name` | 商品分类 |
| `operating_stock` | 在营库存 |
| `operating_machine_count` | 在营设备数量 |
| `operating_machine_names` | 在营设备列表 |
| `operating_channel_count` | 对应设备货道数量 |
| `operating_channel_info` | 对应设备货道信息 |
| `period_sale_quantity` | 周期内销售数量 |
| `period_refund_quantity` | 周期内退款数量 |
| `period_net_sale_quantity` | 周期内净销售数量 |

## 统计口径

- 设备在营状态：`machine.is_operating = is_operating`；不传时默认 `1`（1 在营、2 在库、3 停营）
- 设备有效：`machine.status = 1`
- 货道有效：`machine_channel.status = 1`
- 商品范围：在有效在营设备货道上存在 `g_id > 0` 的商品
- 在营库存：对应在营设备有效货道的 `SUM(machine_channel.stock)`
- 在营设备数量：对应商品的 `COUNT(DISTINCT machine_channel.m_id)`
- 对应设备货道数量：对应商品的 `COUNT(machine_channel.mc_id)`
- 周期内销售数量：`sale_orders_details.quantity`，关联 `sale_orders.pay_status = 3`
- 周期销售限定：只统计该商品当前对应在营设备上的订单明细
- 默认不依赖 `sale_orders_goods_count` 等统计汇总表，直接从订单明细实时聚合

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `pageNum` | int | 否 | 每页条数；不传或为 `0` 返回全部 |
| `page` | int | 否 | 当前页，分页时使用 |
| `g_id` | string/int/array | 否 | 商品 ID，支持逗号分隔或数组 |
| `g_name` | string | 否 | 商品名称模糊查询 |
| `sku` | string | 否 | SKU 模糊查询 |
| `m_id` | string/int/array | 否 | 设备自增 ID，支持逗号分隔或数组 |
| `machine_id` | string | 否 | 设备编号；多个用逗号分隔时按 IN 查询，单个按模糊查询 |
| `ao_id` | int | 否 | 组织 ID |
| `is_operating` | int | 否 | 设备在营状态：`1` 在营、`2` 在库、`3` 停营；默认 `1` |
| `start_time` | int/string | 否 | 销售周期开始时间，支持时间戳或 `YYYY-MM-DD` / `YYYY-MM-DD HH:mm:ss` |
| `end_time` | int/string | 否 | 销售周期结束时间，支持时间戳或 `YYYY-MM-DD` / `YYYY-MM-DD HH:mm:ss` |
| `create_time` | string | 否 | 销售周期快捷参数，格式：`2026-06-01~2026-06-22` |
| `sort_by` | string | 否 | 排序字段：`g_id`、`operating_stock`、`operating_machine_count`、`operating_channel_count` |
| `sort_order` | string | 否 | `asc` 或 `desc`，默认 `desc` |

## 请求示例

```json
{
  "m_id": "588",
  "sku": "1606100760",
  "g_name": "示例商品",
  "page": 1,
  "pageNum": 15,
  "is_operating": 1
}
```

更多筛选参数示例：

```json
{
  "token": "{{token}}",
  "page": 1,
  "pageNum": 20,
  "is_operating": 1,
  "g_name": "可乐",
  "create_time": "2026-06-01~2026-06-22",
  "sort_by": "operating_stock",
  "sort_order": "desc"
}
```

## 导出请求示例

```json
{
  "token": "{{token}}",
  "is_operating": 1,
  "g_name": "可乐",
  "create_time": "2026-06-01~2026-06-22",
  "sort_by": "operating_stock",
  "sort_order": "desc"
}
```

## 导出响应示例

```json
{
  "state": 200,
  "msg": "导出中",
  "data": []
}
```

## 返回字段

| 字段 | 说明 |
| --- | --- |
| `g_id` | 商品 ID |
| `g_name` | 商品名称 |
| `sku` | SKU |
| `gc_name` | 商品分类名称 |
| `pic` | 商品图片 |
| `operating_stock` | 在营库存 |
| `operating_machine_count` | 在营设备数量 |
| `operating_machine_ids` | 在营设备 ID 列表 |
| `operating_machine_list` | 在营设备列表，每个设备含对应货道数量、库存与货道明细 |
| `operating_channel_count` | 对应设备货道数量 |
| `operating_channel_list` | 当前商品对应的全部货道明细 |
| `period_sale_quantity` | 周期内销售数量 |
| `period_refund_quantity` | 周期内退款数量 |
| `period_net_sale_quantity` | 周期内净销售数量，等于销售数量减退款数量 |

分页查询时，分页对象额外返回 `request_params`，用于回显本次已生效的业务参数；该字段不包含 `token` 或未支持参数。

> 为保持现有前端和导出兼容，返回字段中的 `operating_*` 名称不变；当筛选 `2` 或 `3` 时，这些字段表示所选设备状态范围内的统计值。
