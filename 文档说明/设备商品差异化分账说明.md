# 设备商品差异化分账

## 业务规则

- 新增 `rule_mode=4`：设备商品分账。
- 分账规则通过 `revenue_rule_machine` 绑定设备。
- 策略明细通过 `revenue_rule_item.g_id` 绑定商品。
- 同一个商品可在不同设备绑定不同的 `rule_mode=4` 策略，实现不同分账比例或金额。
- `calc_type=1`：按订单商品明细总金额比例分账。
- `calc_type=2`：按每件商品固定金额分账，分账金额为 `calc_value × quantity`。
- 同一策略、同一商品可以配置多个接收账户，但固定比例合计不能超过 100%。
- 商品分账后剩余金额继续进入普通分账。

## 计算优先级

1. 设备出租分账。
2. 设备商品分账。
3. 未启用设备商品分账时，执行设备整单分账。
4. 未被分配的剩余金额进入普通分账。

## 配置流程

1. 创建 `rule_mode=4` 的分账策略。
2. 使用 `/management/revenue.revenue_rule/addProductItem` 新增商品分账明细。
3. 使用 `/management/revenue.revenue_rule/bindMachine` 将策略绑定设备。

按比例请求示例：

```json
{
  "rr_id": 100,
  "g_id": 700,
  "receiver_ao_id": 2,
  "ra_id": 102,
  "manager_id": 1002,
  "calc_type": 1,
  "calc_value": 10,
  "status": 1
}
```

按每件固定金额请求示例：

```json
{
  "rr_id": 101,
  "g_id": 700,
  "receiver_ao_id": 2,
  "ra_id": 102,
  "manager_id": 1002,
  "calc_type": 2,
  "calc_value": 3,
  "status": 1
}
```
