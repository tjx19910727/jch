# 新分账离线自动化测试说明

## 测试方式

脚本：`tests/revenue_offline_scenarios.php`

隔离检查：`tests/revenue_strategy_isolation.php`

接口文档检查：`tests/revenue_openapi_validate.php`

执行：

```bash
php tests/revenue_offline_scenarios.php
php tests/revenue_strategy_isolation.php
php tests/revenue_openapi_validate.php
```

该脚本不连接数据库、不调用真实支付、不写入业务表。所有订单、账户、收款策略、设备策略、阶梯营业额均在脚本内存中构造。

## 覆盖场景

- 普通分账：A 设备销售 A 商品，A 获得订单全额。
- 设备出租：A 设备销售 B 商品，B 按 100% 获得商品金额。
- 设备固定比例分账：设备绑定 B 20%、C 30%。
- 阶梯分账：本单后累计达到 5000 以上但未到 8000。
- 阶梯分账：本单后累计达到 8000 以上，B 命中 30%。
- 支付成功：待支付分账单变为已结算。
- 支付取消：待支付分账单变为已取消。
- T+1 分账：支付成功后进入待结算，到计划时间后结算。

## 边界说明

该测试验证的是业务规则和金额计算，不验证以下数据库集成能力：

- 表字段与模型字段是否完全匹配。
- `RevenueCalculator` 对真实 `Db` 查询的兼容性。
- 后台接口权限、分页、筛选。
- 真实订单支付回调、退款回调、设备出货/MQ/通知。
- 账户管理人余额真实加减。

数据库连接允许后，还需要继续执行联调自检清单中的真实数据链路测试。
