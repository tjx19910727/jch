# 角色权限模板

## 业务规则

- 模板节点以 `nodeList` 保存，Key 为节点 ID，Value 为数据权限类型 `d_type`。
- 一个角色最多关联一个模板，通过 `auth_role.template_id` 保存。
- 角色关联模板时，模板节点会覆盖角色当前节点。
- 修改模板节点后，所有关联角色会立即同步。
- 账号绑定角色前，系统会再次同步模板节点，确保账号获得最新权限。
- 已关联模板的角色不能再通过旧角色节点接口手工修改。
- 将角色的 `template_id` 修改为 `0` 可解除模板关联，解除后保留角色当前节点。
- 未关联模板的历史角色继续使用原有角色节点配置。

## 接口

| 接口 | 参数 | 说明 |
| --- | --- | --- |
| `/management/auth.auth_role_template/getList` | `name,status,pageNum` | 查询模板列表 |
| `/management/auth.auth_role_template/getFind` | `art_id` | 查询模板 |
| `/management/auth.auth_role_template/add` | `name,desc,status` | 新增模板 |
| `/management/auth.auth_role_template/update` | `art_id,name,desc,status` | 修改模板 |
| `/management/auth.auth_role_template/del` | `art_id` | 删除未使用模板 |
| `/management/auth.auth_role_template/getNodes` | `art_id` | 查询模板节点 |
| `/management/auth.auth_role_template/saveNodes` | `art_id,nodeList` | 覆盖保存模板节点并同步角色 |
| `/management/auth.auth_role_template/apply` | `art_id,role_id` | 将模板应用到角色 |

`saveNodes` 请求示例：

```json
{
  "art_id": 1,
  "nodeList": {
    "101": 1,
    "102": 2,
    "103": 3
  }
}
```
